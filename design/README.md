# 给设计负责人的一页说明

欢迎加入！这一页只讲你需要知道的，不用懂代码。

## 这个项目是什么

**dsh-shelf（学习书架）** 是 DeepSeek Harness 里的一个插件。Harness 是一个 AI 桌面应用，类似 ChatGPT 客户端，可以装插件扩展功能。

我们想把**一本书从读到用**的过程串起来：

```
阅读 → 记笔记（批注 / 错题）→ 和 AI 聊心得 → 排版成图文分享出去
```

目标：**逻辑清晰、界面美观、功能好用**。功能宁少勿乱。

## 现在有什么（v0.1）

- **书架**：学习目标 › 科目 › 资料（PDF 教材或 B 站视频课），一排封面，显示进度。
- **进度**：每本书一个目标日期，自动算出每天该学几节。
- **错题**：截图发给 AI，AI 识别成文字，记到对应的章节下。

## 接下来想做什么

- **笔记** = 批注 + 错题两种。都挂在「某本书 › 某一节」下面。
- **分享卡片**：挑几条笔记，排成好看的图（类似小红书图文）。← 最适合你先发挥的部分
- 阅读器、批注界面：放在后面。

名字都还没定死（「笔记」「分享卡片」「书架」……），**起名欢迎你来改**。

## 第零步：注册 GitHub（让 GPT 带着你做）

GitHub 是放代码和讨论的网站。注册要收邮箱验证码、做人机验证，**这几步得你自己点**，但每一步都可以问 GPT。对 ChatGPT 说：

> 我是电脑小白，要注册一个 GitHub 账号，用来参与一个项目的讨论（Issues 和 Discussions）。请一步一步带我做，每次只说一步，等我说「好了」再说下一步。我卡住时会发截图给你。注册完后，再教我开启两步验证。

注册好后，把**用户名**发给 feolhn，他会把你加进项目。你会收到一封邀请邮件，点「接受」就行。

**（可选）让 ChatGPT 连上 GitHub**：连上之后，GPT 可以直接读项目代码，你就不用每次下载 ZIP。同样可以让 GPT 带你操作：

> 我想在 ChatGPT 里连接我的 GitHub 账号，让你能读 feolhn/dsh-shelf 这个仓库。请一步一步带我做。

连不上也没关系，用下面的「下载 ZIP」一样可以。

## 第一步：装上内测版

你装的是**内测版**（beta），只给 feolhn 和你两个人用，比正式版新，可能有 bug。正式版用户装的是 `dsh-shelf`（不带 `@beta`），两者不要混装。

**不用自己看下面的步骤**，把这段话复制给 ChatGPT，它会一步步带你做：

> 我要在电脑上的 DeepSeek Harness 里装一个插件的内测版，说明在 https://github.com/feolhn/dsh-shelf/blob/main/design/README.md 的「第一步：装上内测版」。请一步一步带我做，每次只说一步，等我说「好了」再说下一步。我卡住时会发截图给你。

（下面是给 ChatGPT 看的步骤。）

1. 下载安装 **DeepSeek Harness** 桌面版（0.2.x）。
2. 打开 Harness → **设置** → **插件** → **添加插件** → 选「安装第三方插件」。
3. 在「包名或地址」里输入 `dsh-shelf@beta` → **安装** → 装好后点 **立即启用**。
4. 完全退出 Harness（⌘Q）再打开。左侧导航出现「Memory Palace」、对话标题栏右上角出现书本图标，就装好了。

**有新的内测版时**（feolhn 会在置顶讨论里说版本号）：在插件列表里先**卸载** dsh-shelf，再按第 2、3 步重新装一次，然后重启。
如果提示「安装的是旧版本」：这是 Harness 的安全策略，新发布的版本要过一段观察期。在包名里直接写版本号就行，比如 `dsh-shelf@0.2.0-beta.1`。

**遇到问题**：把截图发给 ChatGPT，说「帮我写一段问题反馈：我做了什么、看到了什么、本来以为会怎样；截图里有真名、聊天记录或路径的话提醒我先打码」，再把它写好的话贴到置顶讨论帖下面。

## 第二步：让 GPT 读懂这个项目

1. 打开 https://github.com/feolhn/dsh-shelf（仓库目前是私有的，要先等 feolhn 把你加为协作者才能看到）→ 绿色按钮 **Code** → **Download ZIP**。
2. 把 ZIP 上传给 ChatGPT（或者在 ChatGPT 里连接 GitHub，选这个仓库）。
3. 第一句话可以这样说：

> 这是一个 DeepSeek Harness 插件的项目代码。我是设计负责人，不写插件代码，只做 HTML 原型。
> 请先读 `design/README.md`（特别是「插件放在哪里」和「原型的边界」）、`WORK.md`，再大致看一下 `src/client/ui/` 了解现有界面。
> 之后帮我做原型时：原型要能放进 `design/frame.html` 的白色区域（先按右侧栏 460 宽做），数据按 `design/sample-library.json` 的结构，颜色用 `design/theme.css`，只做浅色，不做图标。
> 需要新增数据字段时，单独列出来告诉我，我好在 issue 里说明。

之后就是你熟悉的方式：和 GPT 一起做 HTML 原型。

## 插件放在哪里（做原型前必读）

插件不是独立网站，它住在 Harness 窗口里的**两个位置**：

| 位置 | 大小 | 用途 |
|---|---|---|
| **右侧栏**（主要） | 约 460 × 717，和对话并排 | 日常使用。AI 功能（记错题、生成目录）只能在这里用，因为旁边就是对话 |
| **全屏**（左侧导航点「学习」） | 约 860 × 765 | 浏览书架、打勾。没有对话 |

打开 `frame.html` 就能看到：灰色部分是 Harness 自己的，**白色区域才是你要设计的**。
把原型放进 `prototypes/`，用 `frame.html?src=prototypes/你的文件.html` 打开，就能看到它放进 Harness 里的样子。

**原型的边界（less is more）**：
- ✅ 只做白色区域里的内容，先保证右侧栏（460 宽）好用
- ✅ 用假数据演示：长什么样、点哪里、出现什么
- ❌ 不做自己的左侧导航、顶部导航（Harness 已经有了）
- ❌ 不做宣传语、大标题（这是工具，不是官网）
- ❌ 不做真实功能（存数据、调 AI），这些由 feolhn 实现
- ❌ 不用花时间做图标

## 你怎么参与

**1. 做原型**：两个小要求：

- **数据按 `sample-library.json` 的结构来**。这是插件真实的数据格式（内容是假的）。需要新字段（比如批注）可以自己加，在讨论帖里说明一下就行。
- **颜色尽量用 `theme.css` 里的变量**。这是 Harness 官方的浅色配色，在 HTML 里 `<link rel="stylesheet" href="theme.css">` 引入即可。**只做浅色就行，不用考虑深色模式**。

**2. 交流**：整个仓库你都能看（代码、PR、Issues）；想看某个功能是怎么做的，读对应的 PR。**你只在 Discussions（讨论区）里发帖和回复**，Issues 和 PR 由 feolhn 和 AI 根据讨论来开。

- 做好一版原型，把原型文件发给 ChatGPT，再复制这段话：

> 我做了一个界面原型（附件），想分享到 GitHub 仓库 feolhn/dsh-shelf 的 Discussions（Ideas 分类）。请帮我：1）把原型打包成 zip；2）写好帖子的标题和正文，说清楚想改什么、为什么；3）一步一步告诉我怎么发帖、怎么把 zip 和截图拖进去。不要写我不想公开的个人内容。

- 新建：仓库页面顶部点 **Discussions** → 绿色按钮 **New discussion**。
- 附件：HTML 原型打成 zip、截图，直接**拖进输入框**就能上传。
- 和 GPT 的聊天过程也欢迎贴进来（ChatGPT 的「分享」链接）。
- **不知道怎么写？让 GPT 起草，你来粘贴**：

> 帮我把刚才聊的想法整理成一条 GitHub Discussion：一个标题，加上正文（用 Markdown）。正文写清楚：想解决什么问题、大概怎么做、附件是什么。不要写我不想公开的个人内容。

  然后把标题和正文复制到 GitHub 网页上，把截图、原型 zip 拖进去，点发布。
  **不建议让 GPT 直接替你发**：发出去之前，自己看一眼有没有不想公开的内容。
- 回复就像回邮件，一来一回。

**3. 谁拍板**：想法谁都可以提；做不做、什么时候做，由项目主导（feolhn）决定。代码实现由他和 AI 完成，你不需要写插件代码。

## ⚠ 隐私提醒

仓库以后会**公开**，Issues 和 Discussions 里的内容所有人都能看到。

- 贴读书笔记、截图当例子时，避开不想公开的个人内容。
- 截图里别带真名、聊天记录、文件路径等。
